安全導入の合言葉

「最初から全部任せない」

Claude Cowork は通常のチャットより強力です。Claude Desktop 上で動き、あなたが選んだファイルを読み・書き換え、接続サービスやプラグインを使って複数の手順がある仕事を進められます。だからこそ「便利なチャット」ではなく、新人社員を1人雇う感覚で導入するのが安全です。最初は見せる資料を限定し、任せる仕事を限定し、送信・支払・契約・削除などの重要操作は必ず人間が確認します。

全社で安全に始める10ステップ
◎
まず読む
安全な導入の4原則
▼

全社の情報や外部サービスを最初から自由に使わせるのではなく、専用フォルダ・専用プロジェクト・限定した接続先・低リスクな仕事から始めます。原則は次の4つだけ。

原則やってよいこと避けること
小さく始める競合調査・会議資料案・週次レポート案を作らせるいきなり全社データやメールを自由に扱わせる
人間が最終確認メール・請求・契約・採用の下書きを作らせる送信・支払・契約・採否判断を任せる
作業場所を分けるClaude 専用フォルダを作る原本資料が入ったフォルダ全体を渡す
段階的に広げる成果が安定してから接続先を増やす最初から多数のサービスを接続する
ℹ️ Claude Code は前提にしません

Claude Code は資料整理に役立つ選択肢ですが、Cowork 導入の必須手順ではありません。安全に始めるうえで本当に重要なのは、資料・権限・仕事の範囲を小さく区切ることです。

1
導入前に決める
経営者が決める3つのこと
▼

ここを曖昧にしたまま始めると、AI に何を任せてよいか分からなくなり、結果的に権限を広げすぎます。導入作業に入る前に次の3つを決めてください。

決めること内容例
AI に任せる仕事最初の1か月で任せる低リスク業務競合調査、会議資料案、営業週報の要約
AI に任せない仕事人間承認が必須の業務支払、返金、契約、採用判断、顧客への自動送信
AI に見せる情報最初に使ってよい資料・フォルダ商品説明、公開済み資料、営業テンプレ、匿名化した商談メモ

最初は「AI経営企画担当」がおすすめ

外部送信や支払を伴わず、成果物も確認しやすいので、最初の1人に向いています。

初期AI担当任せる仕事初期に向く理由
AI経営企画競合調査、週次レポート、会議資料案外部送信や支払を伴わず、確認しやすい
AI営業企画提案書案、商談メモ整理、FAQ作成送信前確認を残せば安全に始めやすい
AI採用補佐求人票案、面接質問案、候補者比較表採否判断を禁止すれば補助役として使える
AI経理補佐経費分類案、月次資料のたたき台数字確認が必須なので初期は慎重に
2
Step 1
Claude Desktop と利用条件を確認する
▼

Claude Cowork は Claude Desktop アプリの中で使う機能です。Web 版やモバイルでは使えません。次の準備を行います。

確認項目実施内容意味
プランPro・Max・Team・Enterprise の有料プランを確認Cowork が使える状態か（無料プラン不可）
アプリClaude Desktop（macOS / Windows）を最新版にする古いアプリだと機能が出ないことがある
端末会社で使う業務用 PC を決めるPC 上のファイルやアプリに関わるため私物 PC は避ける
ネット環境安定したインターネット接続を用意作業中に切れると中断しやすい
⚠️ アプリは開いたままにする

Cowork は仕事中に Claude Desktop を開いておく必要があります。アプリを閉じるとセッションは終了します。

3
Step 2 ｜ AI会社の憲法
グローバル指示を設定する
▼

グローバル指示（Global instructions）は、すべての Cowork セッションに共通して効く基本方針です。設定 → Cowork → グローバル指示 から登録します。会社共通の安全ルールを、短く・強いルールだけに絞って入れます。

📋 そのまま貼れる｜グローバル指示テンプレート
あなたは当社のAI業務補佐です。最終判断者ではありません。 次の操作は、必ず人間の明確な承認を得てから行ってください。メール・チャット・SNS・フォームの送信、支払、返金、請求確定、契約、署名依頼、採用・解雇判断、行政提出、原本ファイルの上書き、ファイルの永久削除。 作業では、指定されたフォルダ、プロジェクト、接続先、資料だけを使ってください。関係のないファイル、Webサイト、アプリにはアクセスしないでください。 成果物は、経営者が判断しやすいように、1.結論、2.根拠、3.リスク、4.確認が必要な点、5.次に取る行動、の順でまとめてください。 不明点や根拠が弱い内容は断定せず、「未確認」「要確認」と明記してください。
✅ 反映のコツ

グローバル指示は新しいチャットを開いたときに読み込まれます。設定後はすでに開いているセッションを閉じ、新しく始めてください。

4
Step 3 ｜ 部署を1つだけ作る
最初のプロジェクトと「プロジェクト指示」
▼

プロジェクトは、関連する仕事をまとめる専用の作業場所です。専用のファイル・文脈・指示・Memory を持ちます。営業・経理・人事を全部作る必要はありません。初月は1つだけ。おすすめは「AI経営企画室」です。

プロジェクト名最初に入れる資料最初に任せる仕事
AI経営企画室会社概要、商品説明、公開済み事例競合調査、週次レポート、会議資料案
AI営業企画室商品資料、価格表、FAQ、提案書テンプレ提案書案、メール下書き、商談準備
AI採用補佐室求人票、会社紹介、面接基準求人票案、面接質問案、候補者比較表

プロジェクト指示テンプレート（AI経営企画室）

グローバル指示が「会社全体の憲法」なら、プロジェクト指示は「部署ごとの仕事の進め方」です。

📋 そのまま貼れる｜プロジェクト指示
このプロジェクトは、当社の経営判断を助けるための「AI経営企画室」です。 主な仕事は、競合調査、市場調査、週次レポート、会議資料案、社内課題の整理です。外部送信、支払、契約、採用判断、ファイル削除は行わず、必要な場合は必ず人間に確認してください。 調査結果は、必ず情報源、根拠、未確認事項を分けて書いてください。推測は推測として明記してください。 成果物は、経営者がすぐ判断できるように、最初に3行以内の結論を書き、その後に比較表、根拠、リスク、次の行動を続けてください。 会社資料にない内容を会社方針として断定しないでください。分からない場合は「会社方針として未確認」と書いてください。
ℹ️ 業種・自社仕様はここに書く

事業所名・業種特有のルール・レポート様式など自社固有の設定はプロジェクト指示側に書きます。グローバル指示（全社共通の安全ルール）には書きません。

5
Step 4
作業フォルダを小さく用意する
▼

Cowork は選んだファイルを読み・書き・場合によっては永久削除できます。便利な反面、注意が必要です。広いアクセスを与えず、まず Claude 専用フォルダを作りましょう。

Claude_Cowork_Workspace/ ├── 00_company_basic/ 会社概要・商品説明・基本方針 ├── 10_inputs/ AIに読ませる資料の「コピー」 ├── 20_working/ AIの作業途中ファイル ├── 30_outputs_draft/ AIの下書き成果物（人間確認前） ├── 40_outputs_reviewed/ 人間が確認済みの成果物 └── 90_archive/ 古い成果物の保管
🚫 原本を直接触らせない

契約書・給与・財務・顧客名簿・従業員情報は最初から入れないでください。必要になっても、匿名化したコピーや一部だけを使うところから始めます。公式でも「広いファイルアクセスより専用フォルダ＋重要ファイルのバックアップ」が推奨されています。

⚠️ 削除には必ず許可が要る

Cowork はファイルを永久削除する前に明示的な許可（「許可（Allow）」）を求めます。保護はありますが「攻撃リスクはゼロではない」ため、常に注意が必要です。

6
Step 5
Memory は「育てる」が「信じ込みすぎない」
▼

プロジェクトでは Memory が有効で、行った仕事の文脈を記憶し次回に活かせます。Memory はプロジェクトごとに分かれ、別プロジェクトへは持ち越されません。便利ですが、記憶を会社の正式ルールだと思い込まないことが大切です。

✅ よい使い方
  • 「報告書は結論を先に書く」など会社の好みを覚えさせる
  • 週次レポートの形式を覚えさせる
  • プロジェクト内の文体・文脈を覚えさせる
🚫 避ける使い方
  • 重要な承認ルールを Memory だけに任せる
  • 契約条件や価格決定を記憶だけで運用する
  • 他のプロジェクトにも同じ記憶がある前提で使う

正式ルールはグローバル指示・プロジェクト指示・会社資料に書くのが安全です。月1回、次の点検プロンプトで棚卸ししましょう。

📋 月次の Memory 点検プロンプト
このプロジェクトであなたが前提として覚えている当社のルール、好み、業務手順を一覧にしてください。正式な会社ルールと、会話から推測しているだけの内容を分けて書いてください。
7
Step 6-7
プラグイン・コネクタは段階的に広げる
▼

プラグインは、役割や業務に合わせて Claude の働き方を整える仕組み（スキル・コネクタ・サブエージェントのパッケージ）です。コネクタは外部サービス（Google Drive・Gmail・Slack 等）とつながる仕組み。便利な反面、Claude のできる範囲と情報の範囲を広げます。

⚠️ 信頼できるものだけ入れる

プラグインにはローカルで動く仕組みが含まれる場合があります。Claude Desktop の公式ディレクトリの検証済み拡張に絞り、インストール前に要求される権限を必ず確認してください。

コネクタを追加する順番

段階接続するもの注意点
1公開情報・社内の低機密資料機密資料を混ぜない
2カレンダー、会議メモ個人情報・顧客名の扱いに注意
3CRM、営業ツール顧客への送信は禁止し、下書きまで
4会計・決済ツール支払・返金・給与・税務判断は人間承認
5契約・署名ツール署名依頼・契約締結は責任者承認
💡 「接続できるから」ではなく「必要になったら」

まず低リスクなプロジェクトで成果を確認し、次に営業、最後に経理や契約のような重要領域へ広げます。最初の1か月は、プラグインを使う場合でも送信・投稿・支払を含まない仕事に限定してください。

8
Step 8
定期タスク（スケジュール）は「読む・まとめる」から
▼

スケジュール（定期タスク）は、Cowork に定期的な仕事を任せる仕組みです。レポート・要約・調査などを自動で作れます。ただし自動実行はリアルタイムで監視できないため、低リスクな仕事から始めます。

✅ 初期に向く定期タスク
  • 毎週の競合ニュース要約
  • 営業活動の週次まとめ
  • 会議前の資料チェック（下書き）
  • 未対応タスク一覧の整理
🚫 最初は避ける
  • 顧客へのメール自動送信
  • 請求・返金・支払の自動処理
  • 契約書の自動送付
  • 採用候補者の自動合否判定
📋 そのまま使える｜定期タスク依頼文
毎週月曜日の朝に、指定フォルダ内の営業メモと公開情報をもとに、先週の営業活動の要約、今週の優先対応、リスク、経営者に確認が必要な点を1ページにまとめてください。 顧客への送信、カレンダー変更、請求、契約、ファイル削除は行わないでください。必要な場合は「人間確認が必要」と書いてください。
ℹ️ 実行はアプリが開いているときだけ

定期タスクは Claude Desktop が開いていて PC が起きているときに動きます。スリープ中やアプリを閉じていると実行はスキップされ、後で再実行されることがあります。実行後は必ず結果を確認し、不要なタスクは停止・削除してください。

9
初月の進め方
30日で「1つの成功例」を作る
▼

完璧な AI 運用を最初から目指さず、30日で安全に1つの成功例を作ることを目標にします。

期間やること成功条件
1週目グローバル指示を設定し、AI経営企画室を作る禁止事項と承認ルールが明文化されている
2週目専用フォルダに低リスク資料を入れ、競合調査や会議資料案を依頼結果を経営者が確認できる形で出せる
3週目Memory やプロジェクト指示を調整し、成果物の形式を安定させる同じ形式でレポートが出る
4週目プラグインや接続サービスを1つだけ試す送信・支払なしの低リスク業務で効果を確認
✅ 1か月目のゴール

「AI が全部できる状態」ではありません。任せてよい仕事・任せてはいけない仕事・確認が必要な仕事の境界線が見える状態です。これができれば、プラグイン・接続サービス・定期タスクを安全に広げていけます。

✓
経営者用
安全導入チェックリスト
▼

導入前・毎週の運用確認・接続サービス追加前に、次を確認してください。

  • AI の役割：補佐役であり、最終判断者ではないと明記している
  • 禁止事項：送信・支払・返金・契約・採用判断・削除を人間承認にしている
  • 作業フォルダ：Claude 専用フォルダを作り、原本資料を入れていない
  • プロジェクト：最初のプロジェクトを1つに絞っている
  • プロジェクト指示：部署ごとの仕事の範囲を明記している
  • Memory：補助として使い、正式ルールは指示文や資料に書いている
  • プラグイン：検証済みのものだけを入れ、権限を確認している
  • 接続サービス：必要なものだけを段階的に追加している
  • 定期タスク：要約・調査・レポートなど低リスク業務から始めている
  • 結果確認：最初の数回は経営者または責任者が結果を確認している

すぐ使える「AI会社の憲法」ミニ版

導入初日に使える短い憲法です。会社ごとに調整して、グローバル指示またはプロジェクト指示の土台にしてください。

📋 そのまま貼れる｜AI会社の憲法ミニ版
当社のClaude Coworkは、経営者と社員を補佐するAI会社として使います。AIは調査、要約、比較、下書き、資料作成、チェックリスト化を担当します。最終判断は必ず人間が行います。 AIに任せてよい仕事は、競合調査、会議資料案、営業資料の下書き、商談メモ整理、週次レポート案、社内マニュアル案の作成です。 AIに任せてはいけない仕事は、顧客への自動送信、支払、返金、請求確定、契約締結、署名依頼、採用・解雇判断、行政提出、原本ファイルの上書き、ファイルの永久削除です。これらが必要な場合は、必ず人間に確認してください。 指定されたプロジェクト、フォルダ、資料、接続先だけを使ってください。関係のないファイルやサービスにアクセスしないでください。 成果物では、結論、根拠、リスク、未確認事項、次の行動を分けて書いてください。根拠が弱い場合は断定せず、「要確認」と明記してください。
営業担当者向け
自分専用の営業アシスタントを作る

このパートは、現場で働く営業担当者個人が Cowork を「自分専用のアシスタント」にするための実践セットです。「経営者向け」タブの安全原則（送信・支払・契約は人間が最終確認）はそのままに、営業の日々の仕事に直結する設定とテンプレートを用意しました。今後、経理・採用などの役割版も追加していきます。

1
営業 STEP 1 ｜ 基本方針
グローバル指示と「設定場所マップ」
▼

まず、アシスタントの基本方針を決めます。すべてのセッションに効く「グローバル指示」と、どこに何を書くかの地図です。

設定場所と営業での役割

どこに何を書くかを最初に押さえると、設定で迷いません。営業役割ごとの置き場所は次のとおりです。

設定場所営業での役割
グローバル指示営業アシスタントの基本方針（全セッション共通）
営業プロジェクト日々の営業作業をまとめる場所
プロジェクト指示提案・メール・報告の「型」
プロジェクト資料商品資料・価格表・事例・FAQ・提案テンプレ
Memory文体・報告形式・自分の営業スタイル
Small Business プラグイン営業整理・顧客対応・週報の補助
ℹ️ Memory は補助。正本は資料とCRMを見る

Memory はプロジェクト単位で、あなたの文体や報告の好みを覚えるのに向いています。ただし価格・契約条件・最新の案件状況は記憶に頼らず、資料やCRMの元データを必ず確認させてください。

グローバル指示（営業版）

すべてのセッションに効く営業アシスタントの基本方針です。設定 → Cowork → グローバル指示 に貼ります。

📋 そのまま貼れる｜グローバル指示（営業版）
私は営業担当者です。Claudeには、商談準備、顧客理解、営業メール作成、提案書の下書き、商談後フォロー、案件整理、週次報告を支援する営業アシスタントとして働いてほしいです。 回答は営業現場ですぐ使える形に。専門用語を避け、結論・理由・次の行動が分かるよう整理してください。 顧客に送る文章は押し売り感を避け、相手の状況に配慮した自然な文面に。必要に応じて丁寧版/カジュアル版/短い版など複数案を出してください。 顧客情報・価格・契約条件・納期・値引き・特別対応は断定せず、必要なら「社内確認が必要」と明記してください。 商談準備では、顧客の状況・想定課題・提供できる価値・聞くべき質問・想定反論・次の一手を整理してください。

Memory に文体・報告形式を覚えさせる
▼

自分の営業スタイルを一度覚えさせると、毎回指示しなくても文体が揃います。

📋 そのまま使える｜文体を覚えさせる指示
今後覚えておいてください。私は営業メールでは、丁寧だけど堅すぎない文体を好みます。押し売り感が出る表現は避けてください。
⚠️ Memory に頼らないもの

価格・契約条件・個人情報・値引き・最新の案件状況は記憶ではなく元データ（資料・CRM）を見て判断させてください。Memory を営業台帳の代わりにしないこと。

30分でできる初期設定

  • 5分：グローバル指示に営業版テンプレを貼る
  • 5分：「営業プロジェクト」を1つ作る
  • 5分：プロジェクト指示（営業）を貼る
  • 10分：商品資料・価格表・事例・FAQ・提案テンプレを入れる（最新版・公開可のみ）
  • 5分：最初の依頼（商談準備か週報）を1つ試す

営業でやってはいけないこと

🚫 任せない・させない
  • 値引き・契約条件を Claude に判断させる
  • 古い価格表を入れたまま提案させる
  • 顧客の個人情報を必要以上に入れる
  • 下書きを無確認のまま顧客へ送信する
  • Memory を正式な営業台帳として運用する
✅ 安全に効かせる
  • 送信前に必ず自分が文面を確認する
  • 価格・契約・納期は「社内確認が必要」と書かせる
  • 資料は最新版・公開可のものだけにする
  • 複数案を出させて自分で選ぶ
  • 確定情報は資料・CRMの元データで照合する
